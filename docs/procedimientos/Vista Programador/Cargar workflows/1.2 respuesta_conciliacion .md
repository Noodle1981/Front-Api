# Respuesta del Workflow de Conciliación

> **Ruta:** `/programadores/workflows/execution/{id}/pdf/preview`  
> **Acceso:** Programador  
> **Última actualización:** 2026-01-08

---

## Descripción

Documentación de la respuesta generada después de ejecutar el workflow de conciliación. El sistema genera un PDF con 4 páginas de reportes.

---

## Estructura de la Respuesta

### Página 1: Enviar Sucursal
Resumen general del día de operaciones:
- Total de ventas
- Cantidad de tickets y comensales
- Horarios de venta (apertura, primera venta, última venta, cierre)
- Diferencias de caja por medio de pago (MP, Getnet, Efectivo, Cta Cte)
- Ventas por hora (gráfico)
- Facturación (real vs ideal)

### Página 2: Enviar Egresos
Detalle de salidas de dinero:
- Egresos Caja Adición (compras, pagos a proveedores)
- Egresos Mercado Pago (devoluciones)
- Totales por categoría

### Página 3: Enviar No Conciliados
Transacciones que no pudieron conciliarse:
- Mercado Pago (items real vs sistema)
- Getnet (items real vs sistema)
- Efectivo/Cta Cte (items real vs sistema)
- Totales por categoría

### Página 4: Enviar Anulaciones
Productos y ventas anuladas:
- ID Comanda
- Camarero/Mesa
- Producto anulado
- Comentario/Motivo
- Hora y precio

---

## Formato de Datos (JSON)

El servidor Python retorna datos según esta estructura:

```json
{
    "metadata": {
        "fecha": "08/01/2026",
        "dia": "Jueves",
        "turno": "NOCHE",
        "encargado": "Carlos Méndez",
        "hs_apertura": "18:00",
        "hs_cierre": "02:30",
        "sucursal": "CENTRAL"
    },
    "enviar_sucursal": { ... },
    "enviar_egresos": { ... },
    "enviar_no_conciliados": { ... },
    "enviar_anulaciones": [ ... ]
}
```

Ver estructura completa: `docs/Desarrollos/pdf_preferencias/workflow_data_structure.json`
