# Cargar Workflow de Conciliación

> **Ruta:** `/programadores/workflows/upload`  
> **Acceso:** Programador  
> **Última actualización:** 2026-01-08

---

## Descripción

Wizard de carga de archivos Excel para ejecutar el workflow de conciliación de caja. El sistema identifica automáticamente cada archivo por su estructura de columnas.

---

## Acceso

1. Iniciar sesión como **Programador**
2. Menú lateral → **Cargar Workflows**

---

## Proceso de Carga (Wizard)

### Paso 1: Seleccionar Cliente y Sucursal
- Elegir cliente de la lista
- Seleccionar sucursal a procesar

### Paso 2: Cargar Archivos
Subir los 6 archivos Excel requeridos:

| Archivo | Descripción | Columnas Clave |
|---------|-------------|----------------|
| Turnos.xlsx | Registro de turnos | fecha, hora_inicio, hora_fin |
| Reporte Ventas.xlsx | Ventas del sistema | id_venta, monto, fecha |
| Reporte getnet.xlsx | Transacciones Getnet | numero_operacion, monto |
| Ventas MP.xlsx | Transacciones Mercado Pago | id_pago, monto |
| Devoluciones.xlsx | Anulaciones | id_devolucion, monto |
| Caja Adicion.xlsx | Movimientos de caja | importe, detalle |

### Paso 3: Validación
- El sistema valida la estructura de cada archivo
- Identifica tipo por columnas (no por nombre de archivo)
- Muestra checklist de validación ✅/❌

### Paso 4: Confirmar y Ejecutar
- Revisar resumen de archivos cargados
- Click en **"Ejecutar Workflow"**

---

## Después de la Ejecución

1. Se crea un **Batch** (`WorkflowFileBatch`)
2. Se genera una **Ejecución** (`WorkflowExecution`)
3. Redirige a **Historial de Workflows**
4. Disponible: Ver Batch, Preview PDF, Descargar PDF

---

## Estructura de Datos Generada

El sistema genera un JSON consolidado que se envía al servidor Python:

```json
{
    "metadata": {
        "fecha": "...",
        "turno": "...",
        "sucursal": "..."
    },
    "enviar_sucursal": { ... },
    "enviar_egresos": { ... },
    "enviar_no_conciliados": { ... },
    "enviar_anulaciones": [ ... ]
}
```

Ver: `docs/Desarrollos/pdf_preferencias/workflow_data_structure.json`
